01 / The mental model

Two tools.
One clear story.

Git and GitHub are related, but they are not the same thing. One lives beside your code. The other lives on the internet.

Think of it like this: Git is your notebook. GitHub is the library where you can share that notebook with other people.

Glocal tool

Git

Tracks changes to files on your computer. It works offline and remembers every version you choose to save.
