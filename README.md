# Git, demystified.

A small, responsive field guide to Git and GitHub fundamentals.

## Open the site

Open `index.html` directly in a browser. No build step or dependencies are required.

## Structure

- `index.html` - learning page and semantic content
- `css/styles.css` - responsive visual system
- `js/script.js` - command copy and quiz interactions
- `images/` - image assets folder for future additions
